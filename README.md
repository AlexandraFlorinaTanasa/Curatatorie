The Curatatorie project is an application dedicated to managing the activities of a dry cleaner/laundry service, featuring the following core functionalities:

Order and Client Management: Allows the registration and tracking of clients, as well as managing details regarding orders placed for cleaning items.

Service and Item Administration: Manages the types of services offered (dry cleaning, washing, ironing) and the categories of processed items (clothing, textiles).

Processing Status Monitoring: Tracks the status of each individual order (e.g., registered, processing, ready for pickup, delivered).

Workflow Organization: Ensures a clear record of daily operations to optimize workflow and service delivery to clients.
